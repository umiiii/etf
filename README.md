# etfprem：QDII 基金溢价率计算器

用持仓、跟踪指数或所持境外 ETF 的每日数据独立估算 QDII 基金净值，再算出场内溢价率，口径与集思录一致。覆盖集思录 QDII 欧美市场列表里的全部 41 只 ETF，外加全球芯片 LOF（501225），共 42 只。

## 快速开始

```bash
uv sync                                    # 建虚拟环境并安装本包，只用标准库
brew install poppler                       # 定期报告类基金（501225）需要 pdftotext
uv run etfprem update --fund all           # 下载全部基金的数据到 data/
uv run etfprem history --fund all          # 每只基金最近一年逐日溢价率，另写 reports/overview.md 汇总
uv run etfprem history --fund 513100       # 单只基金；--start、--end 指定任意区间
uv run etfprem estimate --fund 513100      # 最新交易日的估算净值与溢价率，会先刷新最近数据
uv run etfprem check                       # 用集思录列表的当日快照核对收盘价、公布净值和溢价率，收盘后运行
uv run python -m unittest discover -s tests -v

# 溢价率与后续价格走势的建模分析（需要 numpy、statsmodels）
uv sync --extra analysis
uv run etfprem model --update              # 先下载成立以来的净值与日线，再建模，输出 reports/premium_model.*
```

集思录 cookie 写在 `.env` 的 `JISILU_COOKIE`，用于抓集思录历史溢价和列表做对照，没有也能算。

## 溢价率口径

溢价率 = T 日收盘价 / 前一个 A 股交易日 D 的基金净值 − 1。

- QDII 净值 NAV(D) 在 T 日晚间才公布，所以 T 日只能用估算值。已公布净值的日子用公布净值。
- 境外休市时部分基金不公布当天净值（例如 159822 在美国、香港休市日），这些日子的溢价率用估算净值，下一天的估算从更早的公布净值接续。
- 长假后的首个交易日，D 之后境外市场又交易了几天，按这个口径算出的溢价率会失真。报告另给一列“开盘公允价值溢价率”，补上这几天的境外涨跌和当天汇率。

## 估算方法

所有方法共用一个框架：算出持仓从前一净值日 Dp 到 D 的涨跌 r，用过去 20 个净值日的官方净值回归出真实敞口 E，锚定官方净值 NAV(Dp) 往前推一天。

```
estNAV(D) = NAV(Dp) × (1 + E × r) × 汇率(D) / 汇率(Dp) − 年费率 × 自然日 / 365
```

E 吸收现金仓位、分红和跟踪误差的平均影响，回归只用上市之后的净值日，建仓期的现金仓位会把它拉偏。四类方法的区别在于 r 从哪里来。

| 方法 | 基金 | r 的来源 |
|---|---|---|
| 申赎清单篓子法 | 159509、159518、159529，沪市 513350 借用 159518 的清单 | 深交所每日申赎清单里的成分股股数 × 美股收盘价，计入税后分红 |
| 定期报告篓子法 | 501225 | 最新一份定期报告披露的 8 只 ETF 比例，固定权重，海外与 A 股敞口分别回归 |
| 指数法 | 29 只 | 跟踪指数的日线，优先用净收益或全收益版本 |
| 持仓 ETF 法 | 8 只联接型 ETF | 所持那只境外 ETF 的基金净值或收盘价 |

### 各基金实际的估值口径

把估算误差和基金合同对照，查出以下几处与“中间价 × 收盘价”的默认做法不同。华夏的汇率、巴西 ETF 的套算和 520580 按净值估值在基金合同里有明文条款，其余是从净值数据反推出来的，都逐日验证过。

- **汇率。** 大多数基金用当天 9:15 公布的中间价。华夏用外汇交易中心北京时间 16:00 参考汇率（513300、159655，用中间价时误差会从 1bp 以内升到 8bp 以上）。沙特 ETF 用人民币对里亚尔中间价，不是美元或港元中间价套算。巴西 ETF 以美元套算，美元兑雷亚尔取价时点按合同：华夏是北京时间 22:00，易方达是伦敦 16:00。
- **所持 ETF 用净值，不用收盘价。** 联接型 ETF 按被投资 ETF 公布的基金净值估值。这些 ETF 在香港、新加坡几乎没有成交，收盘价常常几天不变，用收盘价误差会大几十倍。巴西 ETF 例外，合同规定按 B3 收盘价。
- **指数版本。** 法国 CAC40 用净收益指数，价格指数在 4 到 5 月分红季会系统性偏低。MSCI 美国 50 用净收益指数。中证海外中国互联网系列的人民币版按市场汇率折算，基金按中间价折算，所以改用港元或人民币全收益版本，指数含 A 股时再扣掉 A 股的汇率差。
- **公布时点。** 2830.HK 的净值要到下一个港股交易日才公布。南方（159329）在每次港股假期都顺延到之后的净值日，华泰柏瑞（520830）只在圣诞、复活节长假时顺延。

## 与集思录核对

- **历史表。** 集思录只给最近 51 个交易日。用公布净值算出的溢价率与集思录逐日对照，所有基金都在两位小数舍入以内。例外有两类：501225 在 2026-09-04 两边的收盘价差 0.001 元；集思录在净值发布延迟时沿用更早的净值（例如 520580、159822 在 2026-07-01），这些日子口径不同，单独列出，不参与比较。
- **列表快照。** 集思录不保存两只沙特、两只巴西和 159687 的历史溢价，513730 的历史停在 2025-09。`etfprem check` 用收盘后的列表快照逐只核对收盘价、最新公布净值和溢价率，补上这几只的核对。2026-10-16 收盘后的快照里，42 只基金的这三项全部与集思录一致。

## 新增一只基金

在 `src/etfprem/config.py` 的 `FUNDS` 里加一项。

- **跟踪指数或联接型 ETF。** 用 `_index(代码, 名称, 市场, 年费率, Series(...))`。`Series` 写明缓存名、数据源、代码、计价货币。汇率默认按计价货币取中间价；华夏基金加 `fx16=True`。
- **深市 ETF 用清单篓子。** 用 `_pcf(...)`。沪市没有历史清单，可以用 `_sibling(...)` 借用跟踪同一指数的深市 ETF 的清单。
- **定期报告类基金。** 设 `holdings="reports"`，把报告里出现的每只持仓写成一个 `Asset`，包括行情代码、市场、币种和名称关键词。报告里出现未配置的持仓时，`update` 会打印出来。

新增后先看 `history` 输出的净值误差。误差明显大于同类基金时，通常是汇率口径、指数版本或公布时点不对，可以对照基金合同“估值方法”一节。

## 已知局限

- **沪市没有历史申赎清单。** 上交所只提供当天的清单，沪市基金只能用指数，或借用跟踪同一指数的深市 ETF 的清单。
- **深交所清单服务器请求过快会封禁约一小时。** 程序已改为单线程慢速下载。
- **指数没有免费日线时只能找替代。** 标普生物科技指数用跟踪同一指数的美国 ETF（XBI）代替，误差 3.8bp。它的清单篓子还不能用：调出指数后才合股的股票（例如 GOSS），Nasdaq 复权价会把它早期的价格放大几十倍，清单股数又看不到这次合股。
- **几只基金受限于免费数据。** 520580 的基金公司用的汇率不是纯中间价，被投资 ETF 的净值也只有 3 位小数，误差约 8bp；两只巴西 ETF 的雷亚尔取价时点与央行询价公告差几分钟，误差 7 到 10bp。
- **联接基金的实时估算依赖被投资 ETF 的净值公布时间。** 南方东英的净值在 T 日白天公布；利安（520580）要晚一到两天，T 日实时估算时只能沿用更早的净值。
- **真实敞口靠回归估计。** 现金比例或调仓方向突变后要几天才能跟上；上市不足 10 个净值日时敞口取 1，159100 上市首日的误差因此达到 219bp。
- **个别口径来自少量样本。** 520830 只在圣诞、复活节长假时顺延，依据是 2024 到 2026 年的 6 次港股假期，2025 年圣诞它又多晚了一天，规则覆盖不到；中证合成指数里的 A 股权重取自 2026-10-14，权重变化大时要更新。
- **集思录历史表只提供最近 51 个交易日。** 更早的日子只能和公布净值对照。

## 溢价率与后续价格走势

`etfprem model` 用 159509 和 501225 上市以来约三年的数据，检验溢价率能否预测之后的价格。

**恒等式。** 价格对数收益 = 净值对数收益 + 对数溢价的变化。所以溢价对价格的预测力，可以拆成它对净值的预测力和它对溢价自身的预测力。

**结构模型。** 对数溢价 = 体制锚 + 错误定价 + 信息领先。锚是随机游走，代表申购额度、暂停申购等体制；错误定价按 AR(1) 衰减；信息领先是场内交易时段已经反映、参考净值次日才反映的美股信息。模型与次日净值收益联合估计，用卡尔曼滤波和极大似然。

| 结果 | 159509 | 501225 |
|---|---|---|
| 预测溢价变化的回归中显著为负的个数 | 9 / 12 | 7 / 12 |
| 当日溢价变化预测次日净值的 t 值 | +6.6 | +8.3 |
| 预测价格的回归中显著的个数 | 2 / 12 | 0 / 12 |
| 结构模型样本外预测价格的最大 R² | 0.5% | 0.8% |
| 错误定价半衰期 | 1.0 天 | 1.7 天 |
| 信息领先占溢价日变化的方差 | 58% | 49% |

结论有三点：

- **溢价会回归，但主要靠净值追上价格。** 溢价偏高时，往往是场内价格已经提前反映了当晚美股的走势，次日净值随之兑现，价格本身并不下跌。
- **溢价率对之后 1 到 20 个交易日的价格涨跌没有稳定的预测力。** 即使能完全看清错误定价成分，价格可预测性的理论上限也只有 R² 5% 到 7%，样本外实际不到 1%。
- **高溢价放大波动，却没有带来额外收益。** 高溢价体制下，溢价变化贡献价格方差的 37% 到 45%，501225 的价格日波动达到 3.6%，净值只有 2.7%。

详细的回归表、分组结果、稳健性检验和样本外检验见 `reports/premium_model.md` 与 `.html`。
