# etfprem：QDII 基金溢价率计算器

用持仓的每日价格独立估算 QDII 基金净值，再算出场内溢价率，口径与集思录一致。支持两类基金：

| 基金 | 类型 | 持仓来源 |
|---|---|---|
| 159509 纳指科技ETF景顺 | 深交所 ETF | 每日申赎清单（PCF）里的成分股股数 |
| 501225 全球芯片LOF | 上交所 QDII-LOF | 定期报告披露的基金投资明细，持有 8 只美国、A 股、东京的半导体 ETF |

## 快速开始

```bash
uv sync                                    # 建虚拟环境并安装本包，只用标准库
brew install poppler                       # 定期报告类基金需要 pdftotext
uv run etfprem update                      # 下载 159509 的数据到 data/，首次约 4 分钟
uv run etfprem update --fund 501225        # 下载 501225 的数据，首次约 6 分钟
uv run etfprem history                     # 159509 最近一年逐日溢价率，输出到 reports/
uv run etfprem history --fund 501225       # 501225 最近一年
uv run etfprem history --start 2026-01-01 --end 2026-06-30   # 任意区间
uv run etfprem estimate --fund 501225      # 最新交易日的估算净值与溢价率，会先刷新最近数据
uv run python -m unittest discover -s tests -v

# 溢价率与后续价格走势的建模分析（需要 numpy、statsmodels）
uv sync --extra analysis
uv run etfprem model --update              # 先下载成立以来的净值与日线，再建模，输出 reports/premium_model.*
```

集思录 cookie 是可选项，写在 `.env` 的 `JISILU_COOKIE`，只用于抓集思录历史溢价做对照。

## 溢价率口径

溢价率 = T 日收盘价 / 前一个 A 股交易日 D 的基金净值 − 1。

- QDII 净值 NAV(D) 在 T 日晚间才公布，所以 T 日盘中只能用估算值。
- 已公布净值的日子，用公布净值算出的结果与集思录历史表逐日一致，差异只来自两位小数舍入。501225 有一天例外，2026-09-04 两边的收盘价差 0.001 元。
- 长假后的首个交易日，D 之后美股又交易了几天，按这个口径算出的溢价率会失真。报告另给一列“开盘公允价值溢价率”，补上这几天的海外涨跌和当天中间价。159509 的集思录历史表里没有这几天，501225 的有。

## 估算模型

两类基金共用一个思路：用 T 日开盘前已公开的持仓和价格算出篓子涨跌，再用过去 20 个净值日的官方净值回归出真实敞口，锚定前一净值日的官方净值往前推一天。

**ETF：每日申赎清单。** 清单 PCF(T) 给出每 100 万份的成分股股数，还自带 8 位精度的官方净值 NAV(Dp)。

```
r       Σ q·(p(D) + 税后分红) / Σ q·p(Dp) − 1        成分股美元收益，q 按拆股换算到复权口径
estNAV  NAV(Dp) × (1 + E·r) × FX(D)/FX(Dp) − 费用   E 为回归出的真实股票敞口，约 95% 到 98%
```

**LOF：定期报告。** 持仓取 T 日之前已发布的最新一份季报、中报或年报，按发布日生效。

```
c_海外  Σ 报告比例 × 人民币收益（美国、东京 ETF，含汇率变动和税后分红）
c_A股   Σ 报告比例 × 人民币收益（A 股 ETF，后复权价）
estNAV  NAV(Dp) × (1 + β海外·c_海外 + βA股·c_A股) − 费用
```

报告比例按固定权重每日再平衡，因为实测基金经理会频繁调回目标权重。两部分的敞口系数分别回归，结果都接近 1。

`tests/` 里有专门的测试：删掉 T 日开盘后才知道的数据，估算结果必须完全不变。

## 最近一年结果（2025-10-13 至 2026-10-12）

| 指标 | 159509 | 501225 |
|---|---|---|
| 交易日 / 已公布净值 | 242 / 241 | 242 / 242 |
| 溢价率均值 / 中位数 | 19.34% / 18.68% | 15.63% / 13.86% |
| 最高 | 39.78%，2026-10-09 | 47.66%，2026-05-25 |
| 最低 | 10.01%，2025-10-14 | −2.48%，2025-12-11 |
| 2026-10-12 | 32.69%，估算 | 33.05%，公布净值 |
| 净值估算平均绝对误差 | 0.93bp | 3.13bp |
| 净值估算最大误差 | 8.2bp | 16.5bp |
| 溢价率平均绝对误差 | 0.011 个百分点 | 0.037 个百分点 |

501225 误差更大，原因是持仓每季度才披露一次，期间的调仓只能靠回归跟踪。明细与图表见 `reports/`，推导过程见 `PLAN.md`。

## 溢价率与后续价格走势

`etfprem model` 用两只基金上市以来约三年的数据，检验溢价率能否预测之后的价格。

**恒等式。** 价格对数收益 = 净值对数收益 + 对数溢价的变化。所以溢价对价格的预测力，可以拆成它对净值的预测力和它对溢价自身的预测力。

**结构模型。** 对数溢价 = 体制锚 + 错误定价 + 信息领先。锚是随机游走，代表申购额度、暂停申购等体制；错误定价按 AR(1) 衰减；信息领先是场内交易时段已经反映、参考净值次日才反映的美股信息。模型与次日净值收益联合估计，用卡尔曼滤波和极大似然。

| 结果 | 159509 | 501225 |
|---|---|---|
| 预测溢价变化的回归中显著为负的个数 | 9 / 12 | 7 / 12 |
| 当日溢价变化预测次日净值的 t 值 | +6.6 | +8.3 |
| 预测价格的回归中显著的个数 | 2 / 12 | 0 / 12 |
| 结构模型样本外预测价格的最大 R² | 0.5% | 0.8% |
| 错误定价半衰期 | 1.0 天 | 1.7 天 |
| 信息领先占溢价日变化的方差 | 58% | 49% |

结论有三点：

- **溢价会回归，但主要靠净值追上价格。** 溢价偏高时，往往是场内价格已经提前反映了当晚美股的走势，次日净值随之兑现，价格本身并不下跌。
- **溢价率对之后 1 到 20 个交易日的价格涨跌没有稳定的预测力。** 即使能完全看清错误定价成分，价格可预测性的理论上限也只有 R² 5% 到 7%，样本外实际不到 1%。
- **高溢价放大波动，却没有带来额外收益。** 高溢价体制下，溢价变化贡献价格方差的 37% 到 45%，501225 的价格日波动达到 3.6%，净值只有 2.7%。

详细的回归表、分组结果、稳健性检验和样本外检验见 `reports/premium_model.md` 与 `.html`。

## 数据源

| 数据 | 来源 |
|---|---|
| 申赎清单 PCF | 深交所 `reportdocs.static.szse.cn/files/text/etf/ETF{代码}{日期}.txt` |
| 定期报告 | 天天基金公告列表与 PDF，用 pdftotext 抽取基金投资明细 |
| 美股、美国 ETF 日线与分红 | Nasdaq `api.nasdaq.com`，日线已按拆股复权 |
| A 股 ETF 日线 | 腾讯行情后复权价，消除份额拆分 |
| 东京 ETF 日线 | 株探 kabutan.jp，只能回溯约 300 个交易日 |
| 指数历史 | Nasdaq Global Indexes 导出 |
| 中间价 | 中国外汇交易中心，美元和日元，单次查询跨度不超过一年，程序自动分段 |
| 场内日线与实时价 | 新浪行情 |
| 公布净值 | PCF 自带，天天基金作补充与交叉核对 |
| 历史溢价对照 | 集思录，需要 cookie |

## 新增一只基金

在 `src/etfprem/config.py` 的 `FUNDS` 里加一项。

- **深交所 ETF。** 设 `holdings="pcf"`，填跟踪指数即可。
- **定期报告类基金。** 设 `holdings="reports"`，把报告里出现的每只持仓写成一个 `Asset`，包括行情代码、市场、币种和名称关键词。报告里出现未配置的持仓时，`update` 会打印出来。

## 已知局限

- 159509 的清单每 100 万份按整数股取整，小权重股票取整误差大，所以篓子法日误差比指数法略高。
- 真实敞口靠回归估计。现金比例或调仓方向突变后要几天才能跟上，长假后单日大涨大跌时误差最大。
- 501225 的估算净值平均每天偏高约 1 个基点，主要出现在下跌日。全年看，净值比报告比例篓子多落后约 1.2%，扣费之外的这部分拖累没有建模。
- 目前只支持深交所 ETF 的申赎清单。沪市 ETF 的清单在上交所，港股持仓需要港元中间价和港股行情，都还没接入。
- 集思录历史表只提供最近 51 个交易日，更早的日子只能和公布净值对照。
